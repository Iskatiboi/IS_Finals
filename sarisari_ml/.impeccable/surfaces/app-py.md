## Direction contract

THESIS: The app is a neighborhood store front, and each ML paradigm is a question painted on its wall. It refuses the default Streamlit white page with small gray analytics blocks.

OWN-WORLD: Saturated enamel yellow signboard with an inset ink keyline and red block lettering with a painted drop shadow, a strip of diamond wire-mesh storefront grille, a green painted tab band, and bright off-white enamel below. Barlow workhorse text with one heavy poster display face.

STORY: The panel sees a store, reads the store question first, sees the algorithm answer it in plain language, and leaves remembering a tool for a real owner.

FIRST VIEWPORT: A full-width yellow sign holds the title at poster scale and the team line beneath it. The grille and green tabs sit directly below, then a large painted store question opens each tab.

FORM: Hand-painted tindahan signboard, grounded candidate 1, chosen by the user as the pick card; seed key c9a20b4e.
